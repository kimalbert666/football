# 球探初盘与显示变盘历史采集

此采集器保存球探页面标注的初盘、显示的赛前变盘行及两者核对结果。历史回读不计入真实赛前预测样本，暂不进入模型训练。

GitHub工作流 `F4 Titan Opening History` 计划每天香港时间08:29运行（实际启动可能延迟），支持手动运行。使用现有ESPN赛程中前后7天的英超赛事，与球探公开日期赛程逐场核对主客队和开球时间；再检查亚盘页面及公司历史身份。每天最多10场，优先近期比赛及较久未读取的目标，其余列为待采。当前采集公司为AH编号3，保留页面实际公司名称。

如果页面把开球同分钟或之后的报价仍标为“即”，保留原行和异常标记，但 `prematch_quote=false`，不进入赛前统计。只有这一类边界异常时，其余合格赛前行可以归档，状态为 `displayed_history_reconciled_with_exclusions`；原来的 `parse_ok=false` 不改写。其他解析错误、分页或截断仍拒绝通过归档验收。

结果保存位置：

- `data/f4/titan-history/status.json`：本次应匹配、成功匹配、缺失、冲突、待采及采集结果。
- `data/f4/titan-history/events/`：各场最新归档索引。
- `data/f4/titan-history/observations/`：每次不可变的研究档案，含抓取时间、来源证据、原始盘口/水位字段、显示时间、同分钟重复及异常行。

完成赛后读取且初盘与历史最早行一致的赛事不无限重复抓取。此处“一致”指来源内部对账，不证明庄家最早开盘或供应商已记录每一次内部报价变化。分钟精度、未知时区、封盘、分页及无法解析的行会保留；时区和水位制式未核验时不制造UTC报价时间或转换后赔率。原始显示水位仍可保存和对账。

主工作流的T−180/T−60/T−15采集和已保存预测不受此研究归档替代。新任务不发日常Issue、不自动调整权重、不下注。来源失败保存状态；程序退出成功不等于每场数据合格，应查看`reconciled`及逐场结果。代码/运行环境失败仍可能触发GitHub故障通知。

发布验收记录见 `data/f4/titan-history/acceptance-20261103.json`。固定历史案例及多场读取用于验证解析与访问能力；正式每日任务、覆盖率及持续可用性须以随后真实运行档案核查。
