# f4 盘口、价格与主客场统计

原始赛前记录已经保存主客队、主队视角让球、双方十进制赔率、公司与实际采集时间。本次补充自动报告的交叉统计，不修改原始快照或模型权重。

`engine/scripts/f4_ah_patterns.py`从已核对赛果身份的最早有效T−15快照结算。分组包含实验、公司、让球绝对值、上／下盘、让球方所在主／客场、价格区间。平手盘另列主客方向，不强行指定上盘。当前累计报告在`data/f4/reports/latest.md`，结构化统计在`data/f4/ah/latest.json`的`price_venue_diagnostics`；每月报告只用该月开球的配对比赛。

按用户指定的价格范围固定五个互不重叠的描述区间：

| 十进制赔率 | 口径 |
|---|---|
| `<1.75` | 不并入1.75–1.85 |
| `1.75≤赔率≤1.85` | 两端包含 |
| `1.85<赔率<1.90` | 两端均不包含 |
| `1.90≤赔率≤2.00` | 两端包含 |
| `>2.00` | 不并入1.90–2.00 |

这里的价格含本金。若使用香港盘纯盈利水位，需减1；例如十进制1.98对应0.98。这些区间用于描述用户关注的问题，不是已验证的高低水分类或模型阈值，也不限制连续价格特征或其他合法盘口。

全赢、半赢、走盘、半输、全输分开；正收益比例为全赢加半赢除以全部该组比赛，走盘留在分母，另外报告全赢率。每侧每场模拟1单位的净收益仅是按赛前价格全选该组的市场描述，不是f4已预测命中或可成交利润。不同公司不混算水位与升降盘；同场两侧、多个窗口或实验不增加独立比赛数。

## 怎样进入模型研究

这些分组先回答“当时让多少、价格多少、在哪个场地、结算怎样”。若研究同档对手为什么让球不同，还需要当时可用的实力评级、对手强度、休息与阵容条件；不能用未来排名为过去比赛分档。现有M2候选使用赛前可用的评级差，缺评级就标记不足，不凭主观相似补数。

f2现有接口提供比分等点预测，不提供亚盘历史水位。f3有赔率快照及主场因素，但竞彩整数三向让球与亚洲两向四分之一盘不同，其主场10%也是规则权重，不能替代验证得到的效应。

分组结果不自动改规则或权重。候选仍按时间顺序区分训练、验证、测试并等待真实赛前预测；研究期只发月报与重要故障，新增统计本身不产生额外通知。
