# f4 准确率审查与改进（2026-10-05）

本轮按用户指定，用 GPT‑6.1 Sol 进行独立代码审查和原始研究核查。结论是先修正会误导判断的计算与比较，再验证新模型。代码检查通过不能证明预测命中率提高。

## 已落实的 v2 改动

1. **比较同一个盘口的水位变化。** 旧M3直接比较两个时点各自选中的代表盘口。代表盘从主让0.25变成主让0.5时，旧价1.94→新价1.96可能被解读为主队升水；但如果早期同一主让0.5价格其实为2.10，真实同合约变化是2.10→1.96，方向相反。v2必须在早期快照找到当前盘口的唯一报价，再计算变化；没有则M3缺特征。只有两边都有公司主盘认证，才另记主盘升降；程序平衡选线不会冒充公司升盘。
2. **直接评价上下盘方向。** 方向取正收益概率较大的一侧；全赢或半赢算正收益命中，走盘留在分母且不算命中。全赢率、五类结算、平均赔率、模拟ROI与覆盖率分别报告。原来的五类结算分类准确率继续保留，不能冒充方向命中率。旧EV最高方向另作诊断，不和命中率最高方向混用。
3. **按验证集命中率选参数，保留概率护栏。** 仍以正则五类log loss拟合，正则网格固定为0.1／1／10。以同一候选网格中验证log loss最小的版本为参考，只有log loss绝对增加不超过0.01、Brier增加不超过0.02、五类RPS增加不超过0.005的参数才参与命中率比较；并列按log loss、网格顺序取值。容差是事先规定的探索设置，不能称为已验证最佳容差。最终测试数据不参与选参。
4. **按同场、同窗口比较。** 训练／验证／测试按完整UTC周60%／20%／20%切分，结果尚未可用的边界样本剔除。候选因缺特征而覆盖不同比赛时，另报两两及三模型共同测试交集；真实已保存预测另按同实验、同比赛、同窗口、同盘口报价求交集。报告配对差和按UTC周重采样的探索区间，少量周不会变成确定优势。
5. **校验真实预测记录。** 模型版本、生成时间、预测时间、盘口、赔率及五类概率必须和原记录一致。赛后生成、非法概率、版本或合约错配不计成绩；同模型同实验的重复比赛只计一次。不同实验／模型版本分别统计。旧记录没有赛前保存新方向规则时，事后计算只能叫旧概率诊断。回撤改为按同时开球批次累计，避免比赛ID排序制造不同回撤。
6. **收紧输入与保留版本。** M2两队各至少有5场已经观察到的历史赛果，避免把初始1500当可靠实力；胜平负辅助报价必须是90分钟市场并保留来源身份、哈希及新鲜度。亚盘倒数赔率归一化更名为价格特征，不能称真实赢盘概率。v1报告原样保留，v2按“月份＋协议版本”另存，候选权重仍为0。

固定研究设置见[f4亚盘v2实验清单](f4-ah-experiment-v2.json)。概率达到55%／60%／65%且估计EV不为负的组，全部作为预先定义的诊断报告；不根据测试成绩挑出某一门槛宣称最强，也不直接发推荐。

## 最值得后续验证的三个研究方向

**统一净胜球分布＋赔率残差，优先级最高。** 用一套主客进球／净胜球分布计算所有合法盘口的结算概率，在同期市场信息基础上只学习少量可重复的偏差。这样可共享数据并约束不同盘口之间的一致性。先比较紧凑Poisson／Skellam与共享有序分布，不能只因结构更复杂就宣布更准。市场分布的推导需说明参数或退还本金概率假设；只有两项亚盘价格不能唯一确定五类结算概率。

**不同盘型、公司与时间的收缩估计。** 共用整体规律，少量盘型／公司的偏差向总体收缩，避免每个±0.25档位都建立独立小样本规则。这个方向可能减少波动，但须和简单正则模型做同场增量、消融比较。

**有时间戳的滞后xG与官方首发。** 放在后面。赛后xG只能用于后续比赛；临场赔率可能已经吸收首发信息，加入阵容并不自动构成优势。有合格来源和可用时间之后，才单独检验它们相对同期盘口的增量。

以上为登记的候选研究方向，尚未拟合或上线成新预测器。当前运行仍是修正后的M1／M2／M3。没有通过新前向证据，不改变模型权重或通知政策。

## 数据能够支持到哪一步

本轮审查时正式亚盘有效记录、已配对赛果均为**0**。已有本地英超历史缓存640场：2024/25完整380场，2025/26部分210场，2026/27部分50场；均缺真实亚盘盘口与价格。50场有初盘胜平负，50场有赛后xG，但缺独立认证的原始可用时间。不能据此重造临场亚盘、初盘或升降盘，也不能计算本次升级的真实提升幅度。

至少120训练／40验证／40测试场只是启动门槛，不是命中率或盈利保证。月度重复历史开发仍是探索；最终认可须来自冻结版本后的真实赛前输出。现有程序自动补数据、执行固定研究与生成月报，不会在关闭GPT后自动阅读新论文。

研究期仍只发送月报和重要故障，方向后台保存。独立赔率备用与调度边界见[f4云端说明](f4-cloud.md)。来源接口接通、程序绿勾和合成测试均不等于已经采到真实英超亚盘窗口。
